     every call (analyze/rank/report each re-extracting = duplicate paid model calls).
     Fixed by the per-subject feature cache in the plugin runtime (W3-3 note in
     runtime.ts): observed records are immutable, so one extraction per subject is
     semantically identical; the fix removes duplicate paid calls, it does not alter
     outputs. 39/39 plugin tests pass unchanged after the fix.

     during the runs; the host's provider retry policy retried them and recovered.
     Recorded in the stderr excerpts below — real-world behavior, not a failure.
  3. With a 503 kill status the AI-SDK retried sampling failures until tools timed out;

     FALLBACK path, not the retry policy. The first run-B attempt (2/6 tools) is
     recorded here as an honest iteration; the final run B passed 6/6.
