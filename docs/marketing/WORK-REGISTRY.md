**Execution model (honest, recorded 2026-10-29 per the TL progress review §9A):** there is exactly ONE agent operating this repository (the TL). Worker A/B/C are **role lanes** — each work order is executed under the discipline of its role (its contracts, gates and evidence requirements), not by parallel independent workers. Every "Owner" above therefore names the TL acting in the role lane; the role lane documents WHICH hat produced the work and which acceptance criteria applied. If/when additional operators join, re-assign the lanes explicitly here.

Shared files are TL-owned or assigned to exactly one role lane at a time. Lanes integrate through reviewed contracts and test fixtures, never unstructured chat assumptions.
